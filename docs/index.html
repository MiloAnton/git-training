Versionning avec Git et GitHub · entraînement

Entraîne-toi à Git

Un terminal Git qui tourne entierement dans ton navigateur. Tu ecris tes commandes, tu les lances, et tu compares ta sortie à celle attendue, ligne par ligne.

Comment ca marche
  • Chaque exercice montre l’exemple à reproduire, issu d’une vraie exécution de la correction.
  • Tu écris tes commandes dans l’éditeur, puis tu cliques sur Vérifier mon programme.
  • Ton travail est conservé dans ton navigateur : tu peux fermer l’onglet et revenir.
  • Les indices et les corrections s’ouvrent avec les codes donnés en séance.
